# 游戏翻译器

Windows 11 游戏截图翻译工具的首个可运行版本。

## 启动

最简单的方式是双击根目录中的 `打开软件.cmd`，也可以直接双击
`dist\GameTranslator.exe`。如果还没有生成 `dist` 文件夹，先在
PowerShell 中运行：

```powershell
.\build.ps1
```

也可以直接运行：

```powershell
.\run.ps1
```

## 当前功能

- Teenage Engineering 风格的白、橙、红工业仪器 UI。
- 可录制的系统全局截图快捷键。
- 可自定义的输出框显示／隐藏全局快捷键。
- 可使用默认 `F6` 或自定义全局快捷键，把选中的可编辑文本翻译后写入剪贴板。
- 文本替换可独立选择 10 种目标语言，翻译完成后按 `Ctrl+V` 即可粘贴译文。
- 多显示器全屏框选截图。
- 截图时在鼠标旁显示指针附近区域的 3× 放大镜，并自动避让屏幕边缘。
- Windows 本地 OCR；韩语优先使用随项目提供的 Tesseract 高精度本地模型，
  高精度模型不可用时自动退回轻量模型。
- 自动识别多行韩语文本块，按从上到下顺序逐句翻译并保留换行。
- 韩语 OCR 会降低异常宽间距、残缺韩文字母和装饰符号候选的优先级，
  避免屏幕纹理与气泡边缘产生的假文字污染译文，同时保留游戏数值和短句单字。
- 韩语 OCR 综合词级置信度、五种版面模式的文本共识和噪声评分选择结果，
  并用干净对白、描边字幕、数字 UI 与小字号复杂背景样例做回归验证。
- 英语、日语、韩语和简体中文候选会并行识别，再按文字体系证据选择语言，
  避免日文假名被形近的韩文字母候选截胡；同时支持中英、日英混合菜单。
- 每张截图同时生成自适应黑白图和原色候选；韩语 Tesseract 也会比较两种
  图像变体，改善红色警告字、彩色字幕及同屏混合明暗背景的识别。
- Windows OCR 按行重建文本，避免多行任务提示被错误合并成一行。
- 韩语候选会识别并奖励 `DPS`、`HP`、`MP` 等 2–10 位大写游戏缩写，
  当其他引擎把它们看成形近数字时优先保留拉丁原词。
- 回归集包含真实游戏截图 `tests/fixtures/real-korean-dps.png`，固定验证
  韩文句子中的 `DPS` 不会再次变成 `085`。
- 多语言 OCR 回归脚本会严格比较字符、空格和 CJK 标点：
  `powershell -ExecutionPolicy Bypass -File .\tests\run-regression.ps1`。
- 接口页面把免密钥与需要密钥的服务分组显示，各组内按综合性能从高到低排列。
- 免密钥选项包括自动备用、Google 直连、Lingva、MyMemory 和
  LibreTranslate 公共／自建节点。
- 需要密钥的选项包括 DeepL、Microsoft Translator 和
  LibreTranslate API。
- 默认使用智能在线翻译：常见游戏菜单先由内置词典即时翻译；完整句子
  优先请求 Google，2.5 秒无结果时并行启用 MyMemory 备用。
- 内置游戏词典可离线翻译常见英／日／韩菜单项，并在所有接口返回后保护
  `DPS`、`HP`、`MP`、`NPC`、`PVP` 等常见游戏缩写，避免变成形近数字。
- Microsoft Translator 支持全球端点、Azure 中国区端点和自定义资源端点；
  中国区可填写 `https://api.translator.azure.cn`，区域资源可同时填写资源区域。
- 截图翻译与文本替换使用统一的 10 秒翻译总时限，超时后会取消请求并反馈。
- 即使第三方接口未响应取消请求，界面也会在 10 秒时恢复；文本替换失败时会主动恢复原文剪贴板。
- 可拖动、置顶、锁定后鼠标穿透的翻译输出框。
- 输出框字体大小与背景不透明度设置。
- 设置以原子方式保存在本机，程序也会阻止重复启动和危险的文本替换快捷键。

## 使用

1. 按默认 `F8` 或自定义快捷键。
2. 框选游戏文字，松开鼠标后等待 OCR 和免费翻译。
3. 点击“调整输出框位置”，拖动输出框并按 Enter 保存。
4. 默认按 `F7` 可关闭或重新显示输出框，按键可在主界面修改。
5. 点击“选择接口”可切换翻译服务并配置对应密钥或服务地址。
6. 点击“文本替换”设置快捷键和目标语言；在普通文本框中选中文字后按
   `F6`，等待托盘提示，再按 `Ctrl+V` 粘贴译文。

翻译默认先查询内置游戏词典，常见菜单无需联网即可立即显示；完整句子优先使用
Google，2.5 秒无结果时并行启用 MyMemory，任一成功即采用。Microsoft Translator
仍可在接口页面中手动选择。程序会把同一截图中的多行对白作为一个上下文整体发送，
以改善代词、语气和连续句子的准确性。

DeepL 和 Microsoft Translator 需要各自的 API 密钥。Microsoft 可填写 Azure
门户“密钥和终结点”页面中的服务地址及区域；LibreTranslate 支持自建服务地址，
API 密钥可选。密钥保存在当前用户的本机设置文件中，不会写入项目目录。

游戏需要使用无边框全屏或窗口化全屏。独占全屏无法保证系统置顶窗口可见。
