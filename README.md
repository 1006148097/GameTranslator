<h1 align="center">游戏翻译器</h1>

<p align="center">
  Windows 11 游戏截图翻译工具：按下快捷键、框选字幕，译文就会显示在屏幕上。
</p>


## 最值得用的功能

- **框选即翻译**：默认按 `F8`，框住游戏字幕，松开鼠标即可识别并翻译。
- **选中文字直接翻译**：默认按 `F6`，译文自动写入剪贴板，再按 `Ctrl+V` 粘贴,让你无缝跟老外聊天！
- **专门优化游戏文字**：支持韩语、日语、英语和简体中文，并能识别中英、日英混合菜单。
- **游戏缩写不乱翻**：重点保护 `DPS`、`HP`、`MP`、`NPC`、`PVP` 等词，减少变成 `085` 一类错误。
- **译文悬浮显示**：输出框可拖动、置顶、调字号和透明度，锁定后不会挡住鼠标操作。
- **多种翻译服务**：默认 Google 优先并自动备用，也可选择 Microsoft Translator、MyMemory、DeepL 等接口。
- **常见菜单秒翻**：内置英／日／韩游戏菜单词典，命中时无需联网。

## 三分钟上手

### 1. 启动软件

最方便的方式是双击项目根目录中的 `启动游戏翻译器.vbs`，不会出现黑色终端窗口。

也可以打开 `dist` 文件夹，双击文件类型为“应用程序”的
`GameTranslator.exe`。它本身不会弹出终端窗口。

> `打开软件.cmd` 是旧的便捷启动器，运行时黑色窗口会短暂闪现；这不代表程序崩溃。

### 2. 截图翻译

1. 进入游戏，建议使用“窗口化全屏”或“无边框全屏”。
2. 按 `F8`，鼠标会变成截图框选工具。
3. 尽量只框住需要翻译的字幕，松开鼠标。
4. 等待识别和翻译，结果会出现在悬浮输出框中。

也可以在主界面点击 **立即截图**。默认按 `F7` 可隐藏或重新显示输出框。

### 3. 调整输出框

- 拖动“字体大小”和“不透明度”滑块可以调整显示效果。
- 点击 **调整输出框位置**，拖到合适位置后按 `Enter` 保存。
- 调整完成后点击主界面右下角的 **保存**。

## 界面与常用设置

### 主界面

主界面集中设置截图快捷键、翻译接口、输出框和文本替换。第一次使用时保留默认设置即可。

### 选择翻译接口

点击 **选择接口** 可以切换翻译服务。小白建议先选 **智能在线翻译**：程序会优先使用
Google，2.5 秒没有结果时自动并行启用 MyMemory。

- **不想填写密钥**：选择“智能在线翻译”或“MyMemory 免费翻译”。
- **国内网络更看重稳定性**：可以申请 Microsoft Translator 密钥后选择微软接口。
- **已经有 DeepL 密钥**：可以选择 DeepL API。

API 密钥只保存在当前电脑的用户设置中，不会写入项目目录。

### 文本替换

点击 **设置文本替换**，可以修改快捷键和目标语言；默认目标语言为英语。使用方法：

1. 在聊天框、记事本或其他可编辑文本框中选中文字。
2. 按默认快捷键 `F6`。
3. 翻译进度和完成状态会显示在与截图翻译相同的悬浮输出框中；译文本身不会显示。
4. 按 `Ctrl+V` 粘贴译文。


## 常见问题

### 双击后只看到黑色窗口闪一下

请确认双击的是 `启动游戏翻译器.vbs`、本机的 `游戏翻译器.lnk` 或
`dist\GameTranslator.exe`，而不是 `打开软件.cmd`。如果程序已经启动，窗口也可能
在其他窗口后面或任务栏中。

### 没有识别到文字

- 框选区域尽量紧凑，只保留字幕和少量背景。
- 避免把人物、图标和大面积复杂纹理一起框进去。
- 小字可以框得更紧，描边字和红色警告字可适当多试一次。

### 翻译一直等待或失败

- 先确认电脑能够联网。
- Google 连接不稳定时，可在“选择接口”中改用 MyMemory 或 Microsoft Translator。
- 单次翻译超过 10 秒会自动取消，不会让界面一直卡住。

### 游戏里看不到翻译框

请把游戏改成“窗口化全屏”或“无边框全屏”。独占全屏模式可能盖住系统置顶窗口。

## 实现原理

下面内容面向想了解技术细节的用户，普通使用不需要阅读。

### OCR 识别

- 同时调用 Windows OCR 和随项目提供的 Tesseract，在英语、日语、韩语和简体中文候选中选择最可信结果。
- 每张截图同时比较原色图和自适应黑白图，改善彩色字幕、描边字和复杂背景文字。
- 韩语使用高精度 `kor_best` 模型，并综合词级置信度、多个版面模式的一致性和噪声评分。
- 按行重建多行对白，过滤残缺韩文字母、装饰符号和异常宽间距，同时保留数值与短句。
- 对 `DPS`、`HP`、`MP` 等大写游戏缩写额外加权，防止形近数字候选覆盖正确结果。

### 翻译流程

- 常见英／日／韩游戏菜单先查询本地词典，命中时直接返回。
- 智能在线翻译优先请求 Google；2.5 秒未完成时并行请求 MyMemory，采用最先成功的结果。
- 可手动选择 Google、Lingva、MyMemory、LibreTranslate、DeepL 或 Microsoft Translator。
- Microsoft Translator 支持全球端点、中国区端点 `https://api.translator.azure.cn` 和 Azure 自定义资源端点。
- 同一截图中的多行文字会作为一个上下文整体发送，减少代词、语气和连续句翻译错误。
- 所有翻译任务统一使用 10 秒总时限，失败时及时恢复界面；文本替换失败时保留原文剪贴板。

### 稳定性与隐私

- OCR 在本机完成，截图不会发送给翻译服务；只有识别出的文字会提交给当前选择的在线翻译接口。
- 设置采用原子写入，减少异常退出导致配置损坏的风险。
- 程序会阻止重复启动和危险的文本替换快捷键。
- API 密钥保存在当前用户的本机设置文件中，不进入项目目录。

## 开发者说明

普通用户下载完整项目后可以直接运行 `dist\GameTranslator.exe`，无需自己编译。

需要重新构建时，在 PowerShell 中运行：

```powershell
.\build.ps1
```

运行全部 OCR 与核心逻辑回归测试：

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run-regression.ps1
```

回归集覆盖干净对白、描边字幕、数字 UI、小字号复杂背景、红色警告字、中英／日英混合菜单，
以及真实韩文 `DPS` 截图 `tests/fixtures/real-korean-dps.png`。

## 运行要求

- Windows 11 x64。
- 截图翻译长句时需要联网；本地菜单词典命中时除外。
- 游戏建议使用窗口化全屏或无边框全屏。
